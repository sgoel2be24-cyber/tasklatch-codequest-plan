# TaskLatch editorial theme

Applied on 1 November 2026 after the user requested a new color scheme and theme. This pass changes presentation styling while preserving the problem, solution, plan and evaluation content.

## Palette

| Role | Color |
| --- | --- |
| Slide background | `#FAF9F6` warm white |
| Main text | `#24292F` charcoal |
| Single accent | `#214E78` deep blue |
| Supporting text | `#637080` slate |
| Rules and diagram outlines | `#D9DEE4` |
| Table headers and key control nodes | `#E9EEF3` |
| Alternate table rows | `#F1F3F5` |

## Typography and hierarchy

- Georgia regular for slide titles, the cover wordmark and the two evaluation count labels.
- Arial for body copy, table content and diagram labels.
- Cover title: 96 px. Slide titles: 44 px. Table and diagram body text: 23 px. Smaller labels are limited to contextual metadata and footnotes.
- Consistent light backgrounds on every slide. Section labels use sentence case.
- Page number only in body-slide footers. Team and presenter identity appear on the cover.
- Editable typography replaces the initial generated latch illustration.
- Pale headers, neutral row bands and hairline table rules replace saturated table blocks.
- Diagram emphasis rests on the user-approval and controller nodes. Other nodes use plain outlines.

The theme is encoded in the PowerPoint color scheme as well as the visible objects. All six tables and both diagrams remain native editable elements.
